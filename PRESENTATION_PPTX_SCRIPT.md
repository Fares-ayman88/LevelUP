# How to convert PRESENTATION.md → PowerPoint (PPTX)

## Option A (best): use Markdown-to-PPT in browser
1. Open https://pandoc.org or a Markdown-to-Slides converter you trust.
2. Provide `PRESENTATION.md` as input.
3. Export as PPTX.

## Option B: use Pandoc locally
1. Install Pandoc.
2. Convert Markdown to PPTX depending on your installed writer/templates.

## Option C: manual import
- Copy slide blocks from `PRESENTATION.md` into PowerPoint slide notes.

---

## Expected slide format
Each slide begins with:
- `### Slide N — ...`

Content fields inside a slide are bullets.
